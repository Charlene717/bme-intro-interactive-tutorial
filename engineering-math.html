CHAPTER A3 · BLOCK A FOUNDATIONS

生醫工程數學

線代、微積分、ODE、傅立葉/拉普拉斯、統計、機器學習——5 大數學工具如何串起 BME 的訊號、影像、控制與建模。

Linear algebra, calculus, ODEs, Fourier/Laplace, statistics & ML — five math toolkits that connect signals, imaging, control, and modeling in BME.

ABET 要求

一、為什麼 BME 數學門檻特別嚴格？

根據 ABET 2025-2026 生醫工程認可標準，BME 學程必須包含微分方程等級的微積分、線性代數、機率統計，以及 ≥ 30 學分數學/科學 + ≥ 45 學分工程主題。這是因為 BME 同時涉及：

  • 連續系統建模（生理控制 → ODE/PDE）
  • 離散訊號處理（ECG/EEG → DFT, z 轉換）
  • 影像重建（CT → Radon, MRI → Fourier）
  • 反問題（impedance tomography, source localization）
  • 不確定性量化（臨床試驗 → 統計、Bayesian）
  • 高維特徵抽取（基因表現 → PCA, manifold）
  • 非線性、隨機、自適應（神經元、群體動態）

Per ABET 2025-2026 BME criteria, programs must cover calculus through differential equations, linear algebra, probability/statistics, plus ≥30 math/science credits + ≥45 engineering credits. BME spans:

  • Continuous-system modeling (physiology control → ODEs/PDEs)
  • Discrete signal processing (ECG/EEG → DFT, z-transform)
  • Image reconstruction (CT → Radon, MRI → Fourier)
  • Inverse problems (impedance tomography, source localization)
  • Uncertainty (clinical trials → stats, Bayesian)
  • High-dim features (gene expression → PCA, manifolds)
  • Nonlinear/stochastic/adaptive (neurons, population dynamics)

概念BME 應用範例
Matrix-Vector Product線性系統、影像變換y = Ax — MRI k-space → image
Eigen-decompositionPCA、模態分析A = QΛQᵀ — EEG ICA、心肌模態
SVD降維、降噪A = UΣVᵀ — MRI 加速
Pseudoinverse (A⁺)最小二乘、反問題x̂ = A⁺y — EEG 源定位

核心觀念：BME 工程師看到大型資料集（影像、訊號、基因表現矩陣），第一個直覺應該是「這背後的線性結構是什麼？」SVD 與 PCA 幾乎是萬用第一步。 Key intuition: Seeing any big dataset (images, signals, gene matrices), the BME engineer's first instinct should be "what's the linear structure here?" SVD/PCA is almost always the right first step.
微積分與 ODE

三、微積分與 ODE

幾乎所有「連續時間的生理過程」都用 ODE 描述：藥物代謝（compartmental model）、神經元動作電位（Hodgkin-Huxley）、心血管循環（Windkessel）、傳染病（SIR）、組織擴散（Fick）。

Almost every "continuous-time physiological process" is described by ODEs: drug PK (compartmental), action potentials (Hodgkin-Huxley), circulation (Windkessel), epidemics (SIR), tissue diffusion (Fick).

一階線性

dC/dt = –k·C  ⇒  C(t) = C₀·e–kt

藥物在血液的「一階消除」。半衰期 t₁/₂ = ln 2 / k。BME 應用：給藥間隔設計、CGM 模型、TDM。

"First-order elimination" of drugs. Half-life t₁/₂ = ln 2 / k. BME applications: dosing intervals, CGM modeling, TDM.

二階阻尼

C·dP/dt + P/R = Q(t)

主動脈彈性（C） + 周邊阻力（R） → 模擬血壓波形。BME：人工瓣膜、CFD 邊界條件。

Aortic compliance (C) + peripheral resistance (R) — models BP waveforms. BME: prosthetic valves, CFD BCs.

非線性

C·dV/dt = –ΣIion(V,t) + Istim

Hodgkin-Huxley 4 維 ODE 系統，可產生 spike、震盪、bistability。

4D ODE system; produces spikes, oscillations, bistability.

PDE 擴散

∂C/∂t = D∇²C – kC

藥物在組織中的擴散、氧氣濃度場、神經電位場。BME：藥物遞送設計、tumor growth、cardiac propagation。

Drug diffusion in tissue, O₂ field, neural potential field. BME: drug delivery, tumor growth, cardiac propagation.

傅立葉與拉普拉斯

四、Fourier / Laplace

Fourier 轉換把訊號分解為不同頻率的正弦波組合。三個版本：CTFT（連續時間）、DTFT（離散時間）、DFT/FFT（離散有限長）。在 BME 中：

  • ECG：心跳頻率 ~1 Hz、心電波形含到 50 Hz
  • EEG：δ (0.5-4) / θ (4-8) / α (8-13) / β (13-30) / γ (30-80) Hz
  • MRI：k-space ↔ image 用 2D FFT 互換
  • CT：Radon 變換 → Fourier slice theorem → reconstruct

Laplace 轉換 X(s) = ∫₀∞ x(t)·e–stdt 是 Fourier 的延伸（含衰減）。線性時不變（LTI）系統的傳輸函數 H(s) 在 Laplace 域是有理多項式比，這讓控制系統的穩定性（極點位置）變得可視。

Fourier transform decomposes signals into sinusoids. Three versions: CTFT, DTFT, DFT/FFT. In BME:

  • ECG: heart rate ~1 Hz, waveforms up to 50 Hz
  • EEG: δ (0.5-4) / θ (4-8) / α (8-13) / β (13-30) / γ (30-80) Hz
  • MRI: k-space ↔ image via 2D FFT
  • CT: Radon transform → Fourier slice theorem → reconstruct

Laplace transform extends Fourier (adds decay). H(s) of LTI systems is a rational polynomial — pole locations make stability visible.

統計與機率

六、統計與機率

描述統計

平均/中位/眾數、標準差、IQR、boxplot；分佈型態（常態、Poisson、bimodal）。

Mean/median/mode, SD, IQR, boxplot; distribution shapes (normal, Poisson, bimodal).

推論統計

t-test、ANOVA、χ²、Wilcoxon、Mann-Whitney；α、β、power、effect size。

t-test, ANOVA, χ², Wilcoxon, Mann-Whitney; α, β, power, effect size.

臨床指標

Sensitivity（真陽率）、Specificity（真陰率）、PPV、NPV、ROC-AUC、likelihood ratio。AI 醫療裝置 FDA 認證關鍵指標。

Sensitivity, specificity, PPV, NPV, ROC-AUC, likelihood ratio — key metrics for FDA AI device clearance.

Bayesian

P(disease | test+) = P(test+ | disease) × P(disease) / P(test+)；先驗分佈、後驗分佈、可信區間。臨床決策核心思維。

P(disease | test+) = P(test+ | disease) × P(disease) / P(test+); priors, posteriors, credible intervals — core to clinical reasoning.

⚠️
易錯： Sensitivity 95% 不等於「測陽性的 95% 是真的」。Bayes 計算下，疾病罕見（prevalence 1%）+ 高敏感度測試，可能 PPV 只有 16%。設計 AI 診斷時 prevalence 不能忽略。 Common mistake: Sensitivity 95% does NOT mean "95% of positives are true." If prevalence is 1%, even a 95% sensitive + 95% specific test gives PPV ≈ 16%. AI diagnostic design must account for prevalence.

程式示例

八、計算 ECG 頻譜與 ROC

import numpy as np
from scipy.fft import rfft, rfftfreq
from sklearn.metrics import roc_curve, roc_auc_score

fs=250; t=np.arange(0,10,1/fs)
# Fake ECG: 1.2 Hz heart, 50 Hz powerline, baseline 0.3 Hz wander
ecg = np.sin(2*np.pi*1.2*t) + 0.4*np.sin(2*np.pi*50*t) + 0.3*np.sin(2*np.pi*0.3*t)

freqs = rfftfreq(len(ecg), 1/fs)
mag   = np.abs(rfft(ecg))
print("Dominant peaks (Hz):", freqs[np.argsort(mag)[-3:]])

# ROC for a clinical classifier
y_true = np.array([0,0,1,1,1,0,1,0])
y_score= np.array([0.1,0.3,0.7,0.8,0.6,0.2,0.9,0.4])
fpr,tpr,_ = roc_curve(y_true, y_score)
print("AUC =", round(roc_auc_score(y_true,y_score),3))
fs=250; t=0:1/fs:10-1/fs;
ecg = sin(2*pi*1.2*t) + 0.4*sin(2*pi*50*t) + 0.3*sin(2*pi*0.3*t);
N=length(ecg);
Y=fft(ecg); mag=abs(Y(1:floor(N/2)+1));
f=(0:floor(N/2))*fs/N;
plot(f,mag); xlabel('Hz'); ylabel('|X(f)|');
