CHAPTER C4 · BLOCK C MECHANICS/TISSUE

藥物遞送系統

從口服膠囊到 LNP-mRNA、從滲透泵到體內 CRISPR——本章把藥物的 ADME 與遞送工程一次說清楚。

From oral capsules to LNP-mRNA, from osmotic pumps to in-vivo CRISPR — this chapter unifies pharmacokinetics with delivery engineering.

PK / PD

一、PK / PD 基礎

藥物動力學（PK, pharmacokinetics）研究「身體對藥物做了什麼」——四步驟 ADME：

  • Absorption — 吸收（口服、注射、皮膚、肺）
  • Distribution — 分布（Vd，分布容積）
  • Metabolism — 代謝（肝臟 CYP450 為主）
  • Elimination — 排泄（腎、膽）

藥物效力學（PD, pharmacodynamics）研究「藥物對身體做了什麼」——劑量-反應關係、EC50、效能（efficacy）、毒性閾值。

關鍵指標：

  • Cmax：血中濃度峰值
  • Tmax：達到 Cmax 的時間
  • AUC：濃度-時間曲線下面積，代表總暴露量
  • t½：半衰期，濃度下降一半所需時間（t½ = 0.693·Vd/CL）
  • CL：清除率（mL/min），= 0.693·Vd/t½
  • F：生物利用率（口服 / IV 的 AUC 比）
  • 治療窗（therapeutic window）：有效劑量（MEC）與毒性劑量（MTC）之間的安全範圍

Pharmacokinetics (PK) = "what the body does to the drug" — the four-step ADME:

  • Absorption (oral, injection, skin, lung)
  • Distribution (Vd, volume of distribution)
  • Metabolism (mostly hepatic CYP450)
  • Elimination (renal, biliary)

Pharmacodynamics (PD) = "what the drug does to the body" — dose-response, EC50, efficacy, toxicity threshold.

Key parameters:

  • Cmax: peak plasma concentration
  • Tmax: time to Cmax
  • AUC: area under the C-t curve = total exposure
  • t½: half-life = 0.693·Vd/CL
  • CL: clearance (mL/min)
  • F: bioavailability (oral/IV AUC ratio)
  • Therapeutic window: safe range between MEC (min effective) and MTC (max tolerated)
💡
記憶口訣：「給藥目標 = 把血中濃度長時間維持在 MEC 與 MTC 之間」。傳統口服藥讓濃度起起伏伏；控制釋放/緩釋的工程目標就是「壓平這條曲線」。 Mnemonic: "Keep plasma level between MEC and MTC for as long as possible." Conventional oral dosing produces peaks and troughs; controlled/sustained release engineering aims to flatten the curve.

控制釋放

四、控制釋放配方

💧

滲透泵 OROS

Alza/J&J 開發；半透膜外殼 + 雷射打的釋放孔 + 內部 osmotic agent（NaCl, 甘露糖醇）+ 藥物。水進入推升 piston → 藥液以接近零階速率擠出。代表：Concerta（methylphenidate）、Procardia XL（nifedipine）。

Alza/J&J; semi-permeable shell + laser-drilled orifice + osmotic agent + drug. Water enters, piston pushes drug out at near-zero-order rate. Examples: Concerta (methylphenidate), Procardia XL (nifedipine).

🧱

基質型

藥物均勻分散在 hydrophilic（HPMC、PEO）或 lipophilic（蠟）基質中；遵循 Higuchi √t 動力學。代表：metformin XR、tramadol ER。

Drug uniformly dispersed in hydrophilic (HPMC, PEO) or lipophilic (wax) matrix; follows Higuchi √t. Examples: metformin XR, tramadol ER.

🎯

儲庫式

藥物核心 + 速率控制膜；釋放速率由膜決定，可達零階。代表：Norplant、Nuvaring、藥物洗脫支架（drug-eluting stents）。

Drug core + rate-controlling membrane; membrane sets the (often zero-order) release rate. Examples: Norplant, Nuvaring, drug-eluting stents.

🌐

水凝膠

PLGA 微球可釋放數週～數月；代表：Lupron Depot（leuprolide 攝護腺癌）、Trelstar、Risperdal Consta。長效抗精神病、HIV PrEP（cabotegravir LA, 8 週）。

PLGA microspheres release over weeks–months; Lupron Depot (leuprolide for prostate Ca), Trelstar, Risperdal Consta. Long-acting antipsychotic, HIV PrEP (cabotegravir LA, 8 weeks).

奈米標靶

五、奈米與標靶

被動標靶（passive targeting）— EPR 效應：腫瘤血管「漏」（孔徑 200–800 nm）且淋巴回流差，奈米粒子（10–200 nm）會被動聚集——Enhanced Permeability and Retention。主動標靶（active targeting）：表面修飾 ligand（抗體、aptamer、folate、RGD）辨識細胞表面受體。

主要奈米平台：

  • 脂質體（liposomes）：磷脂雙層空心球（50–200 nm）。Doxil（PEG-脂質體 doxorubicin）1995 為首支 FDA 核准奈米藥；Onivyde（irinotecan 脂質體）2015 用於胰臟癌。
  • 聚合物奈米粒子（polymeric NP）：PLGA、PLA-PEG；Abraxane（albumin-bound paclitaxel）2005。
  • 微胞（micelles）：兩親性嵌段共聚物自組織。
  • 樹枝狀分子（dendrimers）：PAMAM 等，可精確控制大小與表面。
  • 金奈米粒子：光熱治療（CYT-6091 試驗中）、成像對比、放射增敏。
  • 抗體-藥物複合體（ADC）：單株抗體 + linker + 細胞毒素。Kadcyla（T-DM1）2013、Enhertu（T-DXd, trastuzumab deruxtecan）2019、2024 對 HR+ / HER2-low 乳癌、2025 對胃癌擴張適應症。

Passive targeting — EPR effect: tumor vasculature is leaky (pore 200–800 nm) and lymph drainage poor, so nanoparticles (10–200 nm) accumulate — Enhanced Permeability and Retention. Active targeting: surface ligands (antibody, aptamer, folate, RGD) bind cell-surface receptors.

Key platforms:

  • Liposomes: phospholipid bilayer vesicles (50–200 nm). Doxil (PEG-liposomal doxorubicin), 1995 FDA — first nanomedicine. Onivyde (liposomal irinotecan), 2015 for pancreatic cancer.
  • Polymeric NPs: PLGA, PLA-PEG; Abraxane (albumin-bound paclitaxel), 2005.
  • Micelles: amphiphilic block copolymers, self-assembled.
  • Dendrimers: PAMAM and others — precise size and surface control.
  • Gold nanoparticles: photothermal therapy (CYT-6091 in trials), imaging contrast, radiosensitization.
  • Antibody-drug conjugates (ADCs): mAb + linker + cytotoxin. Kadcyla (T-DM1) 2013, Enhertu (T-DXd) 2019, expanded to HER2-low breast cancer 2024 and gastric cancer 2025.
LNP / mRNA

六、LNP 與 mRNA

LNP（lipid nanoparticle）是過去十年最重要的遞送平台。標準配方有四種脂質：

  1. 離子化脂質（ionizable lipid）：低 pH 帶正電（包裝 mRNA），中性 pH 不帶電（降低毒性）；BioNTech 用 ALC-0315、Moderna 用 SM-102，二者皆 pKa ~ 6.3。
  2. 助劑脂質（helper lipid）：DSPC，提供雙層穩定。
  3. 膽固醇：調節流動性與融合。
  4. PEG-脂質：BioNTech ALC-0159、Moderna PEG2000-DMG，提供 stealth 與顆粒穩定。

製造：用 microfluidic mixer（precision NanoSystems NanoAssemblr、Knauer IJM）讓酒精相 + 水相（含 mRNA）快速混合 → 沉澱形成 LNP，再透析、濃縮。粒徑 80–100 nm。

關鍵產品時間軸：

  • 2018：Onpattro (patisiran)——首支 LNP-siRNA 藥物（治療 hATTR amyloidosis）。
  • 2020 末：Comirnaty (BNT162b2) 與 Spikevax (mRNA-1273)——首批 mRNA 疫苗 EUA，全球 > 130 億劑接種。
  • 2023：Casgevy (exa-cel)——首支 CRISPR 療法，治療鐮刀型貧血 / β-thalassemia（ex-vivo，但仍是 cell + gene engineering 里程碑）。
  • 2024：Verve VERVE-101（PCSK9 鹼基編輯）pause，2025 重啟；Intellia NTLA-2002 體內 CRISPR 治療 HAE（hereditary angioedema）2025 三期啟動。
  • 2025–2026：多家公司開發 in-vivo CAR-T LNP（將 CAR mRNA 送入 T 細胞）；癌症 mRNA 疫苗（Moderna mRNA-4157 + pembrolizumab 黑色素瘤三期）。

器官標靶（SORT, Siegwart 2020）：調整 LNP 中第五脂質可改變肝外標靶——加入正電脂質 → 肺、加入負電脂質 → 脾。

LNPs have been the most important delivery platform of the last decade. Standard formulation = four lipids:

  1. Ionizable lipid: protonated at low pH (packages mRNA), neutral at physiological pH (reduces tox). BioNTech uses ALC-0315, Moderna uses SM-102 — both pKa ~ 6.3.
  2. Helper lipid: DSPC — bilayer stability.
  3. Cholesterol: modulates fluidity & fusion.
  4. PEG-lipid: BioNTech ALC-0159, Moderna PEG2000-DMG — stealth + particle stability.

Manufacture: microfluidic mixers (Precision NanoSystems NanoAssemblr, Knauer IJM) rapidly combine ethanol phase + aqueous mRNA → precipitate LNPs → dialyze and concentrate. Size 80–100 nm.

Timeline:

  • 2018: Onpattro (patisiran) — first LNP-siRNA drug (hATTR amyloidosis).
  • Late 2020: Comirnaty (BNT162b2) & Spikevax (mRNA-1273) — first mRNA-vaccine EUAs; > 13 billion doses worldwide.
  • 2023: Casgevy (exa-cel) — first CRISPR therapy (sickle cell / β-thalassemia); ex-vivo, but a landmark for cell + gene engineering.
  • 2024: Verve VERVE-101 (PCSK9 base editing) paused, restarted 2025; Intellia NTLA-2002 in-vivo CRISPR for HAE entered phase III in 2025.
  • 2025–2026: multiple in-vivo CAR-T LNP programs (deliver CAR mRNA to T cells); cancer mRNA vaccines (Moderna mRNA-4157 + pembrolizumab phase III melanoma).

Organ targeting (SORT, Siegwart 2020): adding a fifth lipid redirects LNPs from liver — positively charged → lung; negatively charged → spleen.

智慧遞送

七、智慧遞送

🌡️

溫度

PNIPAM（poly-NIPAm）LCST ~ 32°C；體溫以下溶解、體溫以上塌陷釋藥。應用：MR-HIFU 觸發遞送、ThermoDox（lyso-thermosensitive liposome doxorubicin）+ HIFU 三期試驗。

PNIPAM LCST ~ 32°C; soluble below body temp, collapses above. Apps: MR-HIFU triggered release, ThermoDox (lyso-thermosensitive liposomal doxorubicin) + HIFU phase III.

⚗️

pH

腫瘤微環境 pH ~ 6.5、內體 pH ~ 5；用 PHIS、PEAA、imidazole 等可質子化基團；釋放控制與 LNP 內體逃逸也使用。

Tumor microenv pH ~ 6.5, endosome pH ~ 5. Use PHIS, PEAA, imidazole groups. Used for release control and LNP endosomal escape.

🧲

磁／超音波

Fe₃O₄ 超順磁奈米粒在交變磁場下發熱（magnetic hyperthermia）；超音波微泡可在血腦屏障打開暫時 BBB（FUS）——已用於 Alzheimer 試驗。

Superparamagnetic Fe₃O₄ NPs heat under AC field (magnetic hyperthermia); microbubbles + focused ultrasound open BBB (FUS) — used in Alzheimer's trials.

💡

光

UV / NIR 觸發釋放；NIR 二窗（700–900 nm、1000–1700 nm）穿透 cm-級組織。應用：photodynamic therapy（PDT）+ 光敏奈米載體。

UV / NIR-triggered release; NIR-II window (1000–1700 nm) penetrates cm-deep tissue. Apps: photodynamic therapy (PDT) + photo-responsive carriers.

⚙️

植入式泵

Medtronic SynchroMed II（鞘膜內 morphine / baclofen / Spinraza）；可程式化、可遙控；MiniMed 670G/780G 胰島素閉迴路結合 CGM（人工胰臟）。

Medtronic SynchroMed II (intrathecal morphine/baclofen/Spinraza); programmable, telemetry-controlled. MiniMed 670G/780G closed-loop insulin + CGM (artificial pancreas).

📍

微針

solid / dissolving / coated / hollow 四類；針長 100–800 μm 不及痛覺神經。可吸收 polymer + 抗原；應用：流感、COVID、HPV 疫苗、insulin、長效避孕。

Solid / dissolving / coated / hollow types; needles 100–800 μm avoid pain nerves. Biodegradable polymer + antigen. Apps: flu, COVID, HPV vaccines, insulin, long-acting contraception.

九、遞送平台決策樹

🌳 遞送平台選擇

Q1.是否為核酸（mRNA / siRNA / CRISPR）？→ LNP（肝為主）；組織標靶用 SORT 或 GalNAc-siRNA。Nucleic acid (mRNA / siRNA / CRISPR)? → LNP (liver default); SORT or GalNAc-siRNA for tissue targeting.
Q2.是否為腫瘤化療？→ 脂質體（Doxil）、ADC（T-DXd）、polymeric NP（Abraxane）；考量 EPR vs active targeting。Tumor chemo? → Liposome (Doxil), ADC (T-DXd), polymeric NP (Abraxane); EPR vs active targeting.
Q3.是否為慢性、需穩態血中濃度？→ 控釋口服（OROS / matrix）、貼片、LA 注射（PLGA depot）。Chronic, need steady plasma level? → Controlled-release oral (OROS / matrix), transdermal, LA injection (PLGA depot).
Q4.是否要繞過 BBB？→ 鞘膜內（SynchroMed 泵、Spinraza）；focused ultrasound + microbubbles 暫時打開 BBB；標靶受體（如 transferrin）。Bypass BBB? → Intrathecal (SynchroMed pump, Spinraza); focused-US + microbubbles to transiently open BBB; receptor-mediated (transferrin).
Q5.是否要刺激觸發（按需）？→ 溫度（PNIPAM + HIFU）、磁性、光（NIR-II）、pH。On-demand triggered? → Thermal (PNIPAM + HIFU), magnetic, light (NIR-II), pH.
程式示例

十、PK 模型程式

(a) 1 室口服 IV bolus 解析解；(b) 2 室 IV 模型 ODE — scipy.integrate.solve_ivp / MATLAB ode45。

(a) 1-compartment IV-bolus analytical solution; (b) 2-compartment IV ODE via scipy.integrate.solve_ivp / MATLAB ode45.

import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp

# (a) 1-compartment IV bolus: C(t) = (D/Vd)*exp(-ke*t)
D, Vd, ke = 100, 40, 0.116   # mg, L, 1/h (t½ ≈ 6h)
t = np.linspace(0,36,200)
C1 = (D/Vd)*np.exp(-ke*t)

# (b) 2-compartment IV: central + peripheral
k12, k21, k10 = 0.5, 0.3, 0.15
def two_comp(t,y):
    Cc, Cp = y
    dCc = -(k12+k10)*Cc + k21*Cp
    dCp =  k12*Cc - k21*Cp
    return [dCc, dCp]

sol = solve_ivp(two_comp,[0,36], [D/Vd, 0], t_eval=t)

plt.plot(t, C1, label="1-comp")
plt.plot(t, sol.y[0], label="2-comp central")
plt.plot(t, sol.y[1], "--", label="2-comp peripheral")
plt.yscale("log"); plt.xlabel("t (h)"); plt.ylabel("C (mg/L)")
plt.title("PK models"); plt.legend(); plt.grid(alpha=.3); plt.show()
D=100; Vd=40; ke=0.116;
t = linspace(0,36,200);
C1 = (D/Vd)*exp(-ke*t);

k12=0.5; k21=0.3; k10=0.15;
A = [-(k12+k10) k21; k12 -k21];
[T,Y] = ode45(@(t,y) A*y, [0 36], [D/Vd; 0]);

semilogy(t,C1,'-',T,Y(:,1),'-',T,Y(:,2),'--','LineWidth',1.4);
legend('1-comp','2-comp central','2-comp peripheral'); grid on;
xlabel('t (h)'); ylabel('C (mg/L)');
