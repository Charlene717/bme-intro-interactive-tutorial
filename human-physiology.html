CHAPTER A2 · BLOCK A FOUNDATIONS

人體生理基礎（工程觀點）

把人體看作多尺度、多迴路、多時域的系統——本章帶你建立 BME 工程師必備的生理地圖。

View the body as a multi-scale, multi-loop, multi-timescale system — this chapter builds the physiology map every BME engineer needs.

尺度層級

一、從分子到系統的多尺度觀

BME 工程師在設計裝置時，必須意識到所有臨床問題都跨越多個尺度。一個心律調節器同時面對：(1) 心肌細胞層級的離子通道（μm, ms），(2) 心臟整體電活動（cm, 100 ms），(3) 全身循環迴路（m, s–min），(4) 終生壽命管理（年）。

Every clinical problem spans multiple scales. A pacemaker simultaneously handles: (1) ion channels in cardiomyocytes (μm, ms), (2) whole-heart electrical activity (cm, 100 ms), (3) systemic circulation (m, s–min), and (4) lifetime device management (years).

心血管系統

二、心血管系統：BME 的核心舞台

🫀 心臟泵浦

四腔室結構（左/右心房、左/右心室），主要循環迴路為：右心 → 肺 → 左心 → 體循環 → 右心。心搏輸出量 (CO) ≈ HR × SV ≈ 75 × 70 mL ≈ 5 L/min；運動可達 25 L/min。

Four chambers (L/R atrium, L/R ventricle). Circuit: right heart → lungs → left heart → systemic → right heart. Cardiac output (CO) ≈ HR × SV ≈ 75 × 70 mL ≈ 5 L/min at rest; up to 25 L/min during exercise.

⚡ 電傳導系統

SA node（竇房結，60-100 bpm pacemaker）→ AV node（房室結，延遲 ~120 ms）→ His bundle → Purkinje 纖維 → 心室。動作電位來自 Na⁺/Ca²⁺/K⁺ 離子通道協調開閉。

SA node (60–100 bpm pacemaker) → AV node (~120 ms delay) → His bundle → Purkinje fibers → ventricles. Action potential emerges from coordinated Na⁺/Ca²⁺/K⁺ ion channels.

💉 血液流變學

血液為非牛頓流體（粘度 ≈ 3-4 cP，水 ≈ 1 cP）。Reynolds 數在主動脈約 4000，多數血管為層流。動脈壓 ~120/80 mmHg、靜脈 ~10 mmHg、肺動脈 ~25/10 mmHg。

Blood is non-Newtonian (μ ≈ 3-4 cP, water ≈ 1 cP). Reynolds in aorta ≈ 4000; most vessels laminar. Pressures: arterial ~120/80, venous ~10, pulmonary ~25/10 mmHg.

📊 氧氣輸送

每 100 mL 動脈血約攜帶 20 mL O₂（97% 結合於血紅素、3% 溶解）。Hb 飽和曲線是 sigmoid（合作性），P50 ≈ 26 mmHg；可被 pH、CO₂、2,3-BPG 右/左移（Bohr 效應）。

Each 100 mL arterial blood carries ~20 mL O₂ (97% bound to Hb, 3% dissolved). Hb-O₂ saturation is sigmoidal (cooperativity), P50 ≈ 26 mmHg; shifted by pH, CO₂, 2,3-BPG (Bohr effect).

💡
BME 應用：幾乎所有心血管裝置（人工瓣膜、支架、左心室輔助器 LVAD、ECMO、心律調節器、ICD、Holter）都要求工程師熟悉這些參數。 BME relevance: Almost every cardiovascular device (prosthetic valves, stents, LVAD, ECMO, pacemakers, ICDs, Holters) requires the engineer to understand these parameters.
互動模擬

三、Hb-O₂ 飽和曲線模擬器

調整 pH、PCO₂、溫度，觀察氧解離曲線左/右移。臨床意義：發燒、運動、酸中毒 → 右移（組織放氧更易）；鹼中毒、低溫 → 左移（Hb 抱緊氧）。

Adjust pH, PCO₂, temperature and watch the curve shift. Clinical meaning: fever, exercise, acidosis → rightward shift (easier O₂ release to tissues); alkalosis, hypothermia → leftward shift (Hb holds O₂).

P50: 26 mmHg

神經系統

四、神經系統：訊號的高速公路

中樞神經（CNS = 腦 + 脊髓）+ 周邊神經（PNS）= 約 86 億神經元，連接 ≈ 100 兆突觸。神經元以動作電位（AP）傳遞訊號：靜息電位 –70 mV，閾值 –55 mV，去極化至 +30 mV，再復極化。傳導速度依有/無髓鞘、軸突直徑差別極大（0.5–120 m/s）。

工程上，神經訊號可從體表（EEG）、皮層（ECoG）、腦內（深部電極、Utah array）擷取。每一種介面都涉及訊號雜訊比、空間解析度、慢性穩定性與生物相容性的權衡。

CNS (brain + cord) + PNS = ~86 billion neurons, ~100 trillion synapses. Neurons transmit signals via action potentials: resting –70 mV, threshold –55 mV, depolarize to +30 mV, then repolarize. Conduction speed varies widely (0.5–120 m/s) by myelination and axon diameter.

Engineers acquire neural signals from the scalp (EEG), cortex (ECoG), or deep tissue (depth electrodes, Utah arrays). Each interface trades SNR, spatial resolution, chronic stability, and biocompatibility.

呼吸與代謝

五、呼吸、內分泌、腎臟與消化

🫁 呼吸系統

潮氣容積 ~ 500 mL；肺活量 ~ 4.5 L；TLC ~ 6 L；FEV₁/FVC < 70% 提示阻塞性病（COPD/氣喘）。氣體交換靠肺泡-毛細管擴散，呼吸頻率 12–20 /min（成人）。BME 應用：呼吸器、CPAP/BiPAP、SpO₂ 監測。

Tidal vol ~500 mL; VC ~4.5 L; TLC ~6 L; FEV₁/FVC < 70% suggests obstructive disease (COPD/asthma). Gas exchange by alveolar-capillary diffusion; RR 12–20/min in adults. BME: ventilators, CPAP/BiPAP, SpO₂ monitoring.

🧪 內分泌與糖代謝

胰臟 β 細胞分泌胰島素、α 細胞分泌升糖素。空腹血糖正常 70–100 mg/dL，糖尿病 ≥ 126 mg/dL。BME 應用：血糖計、CGM（Dexcom Stelo、Abbott Lingo OTC 2024）、人工胰臟 closed-loop pump（如 Tandem Control-IQ）。

Pancreatic β cells secrete insulin, α cells secrete glucagon. Fasting glucose 70–100 mg/dL; diabetes ≥126. BME: glucometers, CGM (Dexcom Stelo, Abbott Lingo OTC 2024), closed-loop artificial pancreas (e.g., Tandem Control-IQ).

🧬 腎臟與電解質

每分鐘約 1.2 L 血通過腎臟（CO 約 20%）。腎絲球過濾率 GFR ~ 90-120 mL/min/1.73 m²。腎衰竭時靠透析（血液 HD / 腹膜 PD）。BME 應用：透析機、人工腎臟（wearable artificial kidney 研究中）。

~1.2 L/min blood flow (20% of CO). GFR ~90-120 mL/min/1.73 m². Renal failure → dialysis (HD/PD). BME: dialysis machines, wearable artificial kidneys (in research).

🍽️ 消化系統

食道-胃-小腸-大腸，吸收靠絨毛微絨毛（總面積 ~ 250 m²）。胃 pH 1.5–2、小腸 pH 6–7。BME 應用：膠囊內視鏡（PillCam）、可吞嚥感測器、胰島素口服奈米遞送。

Esophagus-stomach-small intestine-colon; absorption via villi/microvilli (~250 m² surface). Gastric pH 1.5–2, intestinal pH 6–7. BME: capsule endoscopy (PillCam), ingestible sensors, oral insulin nanodelivery.

骨骼肌肉

六、骨骼肌肉系統

206 塊骨頭 + 600 多條肌肉。骨頭兼具強度（壓縮 ~170 MPa）與韌性，由膠原蛋白 + 羥磷灰石組成。肌肉纖維可分慢肌（type I，耐力）與快肌（type IIa/IIb，爆發）。運動單位（motor unit）= 1 個運動神經元 + 它支配的所有肌纖維，這是力量分級的基本單位。

步態週期分為 stance phase（站立期，60%）與 swing phase（擺盪期，40%）。BME 應用：人工關節（髖、膝）、義肢（如 Össur 智能膝、Otto Bock Genium、Open Bionics Hero Arm）、外骨骼（ReWalk、Ekso）。

206 bones + 600+ muscles. Bone combines strength (~170 MPa compressive) and toughness via collagen + hydroxyapatite. Muscles split into slow (type I, endurance) and fast (type IIa/IIb, power). A motor unit = 1 motoneuron + all fibers it innervates — the basic unit of force grading.

Gait cycle: stance phase (60%) + swing phase (40%). BME applications: joint replacements (hip, knee), prosthetics (Össur, Otto Bock Genium, Open Bionics Hero Arm), exoskeletons (ReWalk, Ekso).

控制理論

七、把生理當作控制系統

人體幾乎所有平衡（恆定）都靠負回饋（negative feedback）維持：體溫、血糖、血壓、pH、滲透壓、激素濃度…等。控制理論的圖式可直接套用：

Almost every homeostatic variable is maintained by negative feedback: temperature, glucose, BP, pH, osmolality, hormones, etc. The control-theory block diagram applies directly:

Setpoint → ± → Controller → Actuator → Plant → y(t) → Sensor →

例：血糖閉迴路控制。感測（CGM）→ 控制器（PID/MPC 演算法）→ 致動器（胰島素幫浦）→ 受控系統（病人）→ CGM 再量。這就是artificial pancreas（如 Tandem Control-IQ、Medtronic 780G、iLet Bionic Pancreas）的工程核心。

Example: Closed-loop glucose control. Sense (CGM) → Controller (PID/MPC) → Actuate (insulin pump) → Plant (patient) → Sense again. This is the engineering heart of the artificial pancreas (Tandem Control-IQ, Medtronic 780G, iLet Bionic Pancreas).

程式示例

八、Hodgkin-Huxley 神經元動作電位

HH 模型是現代電生理的基石（1952 諾貝爾獎工作），用 Na⁺/K⁺ 離子通道 ODE 模擬神經元動作電位。完整版見 1.20 萬條公式，這裡示範最小可跑版本：

The HH model is the foundation of electrophysiology (Nobel-winning work, 1952). It uses Na⁺/K⁺ channel ODEs to simulate AP. A minimal runnable version:

import numpy as np
from scipy.integrate import odeint
import matplotlib.pyplot as plt

# HH parameters (squid axon, original 1952 values)
gNa,gK,gL=120,36,0.3; ENa,EK,EL=50,-77,-54.4; C=1.0

def alpha_n(V): return 0.01*(V+55)/(1-np.exp(-(V+55)/10))
def beta_n(V):  return 0.125*np.exp(-(V+65)/80)
def alpha_m(V): return 0.1*(V+40)/(1-np.exp(-(V+40)/10))
def beta_m(V):  return 4*np.exp(-(V+65)/18)
def alpha_h(V): return 0.07*np.exp(-(V+65)/20)
def beta_h(V):  return 1/(1+np.exp(-(V+35)/10))

def hh(y,t,I):
    V,n,m,h=y
    dV=(I - gNa*m**3*h*(V-ENa) - gK*n**4*(V-EK) - gL*(V-EL))/C
    dn=alpha_n(V)*(1-n)-beta_n(V)*n
    dm=alpha_m(V)*(1-m)-beta_m(V)*m
    dh=alpha_h(V)*(1-h)-beta_h(V)*h
    return [dV,dn,dm,dh]

t=np.linspace(0,50,5000)
sol=odeint(hh,[-65,0.32,0.05,0.6],t,args=(10,))  # inject 10 μA/cm²
plt.plot(t,sol[:,0]); plt.xlabel("ms"); plt.ylabel("V (mV)"); plt.show()
% MATLAB HH model — same equations
gNa=120; gK=36; gL=0.3; ENa=50; EK=-77; EL=-54.4; C=1; I=10;
an=@(V) 0.01*(V+55)./(1-exp(-(V+55)/10));
bn=@(V) 0.125*exp(-(V+65)/80);
am=@(V) 0.1*(V+40)./(1-exp(-(V+40)/10));
bm=@(V) 4*exp(-(V+65)/18);
ah=@(V) 0.07*exp(-(V+65)/20);
bh=@(V) 1./(1+exp(-(V+35)/10));
ode=@(t,y)[(I-gNa*y(3).^3*y(4)*(y(1)-ENa)-gK*y(2)^4*(y(1)-EK)-gL*(y(1)-EL))/C;
            an(y(1))*(1-y(2))-bn(y(1))*y(2);
            am(y(1))*(1-y(3))-bm(y(1))*y(3);
            ah(y(1))*(1-y(4))-bh(y(1))*y(4)];
[t,y]=ode45(ode,[0 50],[-65;0.32;0.05;0.6]);
plot(t,y(:,1)); xlabel('ms'); ylabel('V (mV)');
