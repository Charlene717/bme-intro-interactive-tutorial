CHAPTER B2 · BLOCK B SIGNALS & IMAGES

訊號處理

取樣、濾波、頻譜、偵測、特徵抽取——把雜亂的 ECG / EEG 變成可診斷、可分類、可預測的數字。

Sampling, filtering, spectra, detection, feature extraction — turning noisy ECG/EEG into diagnostic, classifiable, predictive numbers.

取樣與量化

一、取樣、量化與混疊

Nyquist–Shannon 取樣定理：若連續訊號 x(t) 的頻寬 ≤ fmax，則用 fs ≥ 2·fmax 取樣即可完美還原；其中 fs/2 稱為 Nyquist 頻率。低於此率取樣會造成混疊（aliasing）——高頻訊號偽裝成低頻、永久污染。實務防混疊措施：在 ADC 前面放 類比抗混疊低通濾波器，截止 ≈ 0.4·fs。

量化（quantization）是把連續振幅映射到有限位元的離散階梯。N bit ADC 提供 2N 階；量化雜訊功率為 Δ²/12（Δ = 量化步階），故動態範圍 ≈ 6.02·N + 1.76 dB。醫療 ECG/EEG 常用 12–24 bit ΣΔ ADC，動態範圍 ≥ 110 dB。

Nyquist–Shannon theorem: a signal of bandwidth ≤ fmax can be perfectly reconstructed if sampled at fs ≥ 2·fmax; fs/2 is the Nyquist frequency. Under-sampling causes aliasing — high frequencies masquerade as low and permanently contaminate the signal. The fix: an analog anti-aliasing low-pass ahead of the ADC, cutoff ≈ 0.4·fs.

Quantization maps continuous amplitude to a finite-bit ladder. An N-bit ADC has 2N steps; quantization-noise power = Δ²/12, so dynamic range ≈ 6.02·N + 1.76 dB. Medical ECG/EEG use 12–24-bit ΣΔ ADCs with ≥ 110 dB dynamic range.

🚫
致命錯誤：沒有抗混疊濾波器卻直接低 fs 取樣 ECG，60 Hz 工頻雜訊可能混疊成 10 Hz 偽訊號，疊在心跳波形上完全無法區分——軟體濾波無法救回。混疊必須在類比端就攔截。 Fatal pitfall: sampling ECG below fs without an analog anti-aliasing filter — 60 Hz power-line can alias to 10 Hz, indistinguishable from heartbeat content. Software filtering cannot recover this. Aliasing must be stopped in the analog domain.

四大 IIR 原型在「過渡帶陡度 vs 通帶/阻帶漣波」做出不同折衷：

  • Butterworth：通帶最平坦，過渡帶緩；最常用於監測級 ECG。
  • Chebyshev I：通帶有漣波、阻帶平坦；同階比 Butterworth 更陡。
  • Chebyshev II：通帶平坦、阻帶有漣波；EMG 高通常見。
  • Elliptic（Cauer）：通帶與阻帶都有漣波、過渡帶最陡；同階性能最佳但相位最非線性。

The four classic IIR prototypes trade off "transition steepness vs passband/stopband ripple":

  • Butterworth: maximally flat passband, gentle transition — the workhorse for monitoring-grade ECG.
  • Chebyshev I: ripple in passband, flat stopband — steeper than Butterworth at the same order.
  • Chebyshev II: flat passband, ripple in stopband — common for EMG high-pass.
  • Elliptic (Cauer): ripples in both bands, steepest transition — best performance per order, worst phase linearity.
⬇️

Lowpass

保留低頻、抑制高頻。ECG 監測常用 40 Hz、診斷用 150 Hz；移除 EMG 噪聲。

Keep low, attenuate high. ECG monitoring uses 40 Hz; diagnostic 150 Hz. Removes EMG noise.

⬆️

Highpass

移除基線漂移（呼吸 0.3 Hz、出汗）；ECG HPF 截止 0.05–0.5 Hz。

Remove baseline wander (respiration 0.3 Hz, sweating). ECG HPF cutoff 0.05–0.5 Hz.

⇅

Bandpass

留下特定頻段；QRS 偵測用 5–15 Hz、EEG α 用 8–13 Hz、EMG 用 20–450 Hz。

Keep a band. QRS detection 5–15 Hz, EEG α 8–13 Hz, EMG 20–450 Hz.

⊘

Notch

窄阻帶，移除單一頻率（工頻）。Q 值越高、阻帶越窄、暫態振盪越大。

Narrow stop, removes a single frequency (mains). Higher Q = narrower stop but worse transient ringing.

💡
選擇原則：(1) 訊號統計性質不變 → FFT；(2) 訊號分段平穩 → STFT；(3) 訊號含瞬時事件、需要「高頻段時間細、低頻段頻率細」→ wavelet。常見錯誤是對 ECG 整段做一次 FFT 就下結論，這在心律不整下完全失效。 Choosing: (1) statistics invariant → FFT; (2) piecewise stationary → STFT; (3) transient events with "fine time at HF, fine freq at LF" needs → wavelet. A common mistake is running one big FFT over an arrhythmic ECG — that hides the very arrhythmia you're chasing.
偵測演算法

四、事件偵測

🔺 Pan-Tompkins

1985 年提出，至今仍是 QRS 偵測黃金基準：5–15 Hz 帶通 → 微分 → 平方 → 150 ms 移動平均 → 自適應雙閾值（SPKI、NPKI）+ 200 ms 不應期 + 搜尋回退（searchback）。MIT-BIH 上敏感度 99.3%、PPV 99.5%。

Proposed in 1985, still the QRS gold benchmark: 5–15 Hz BP → differentiate → square → 150 ms MA → adaptive dual thresholds (SPKI, NPKI) + 200 ms refractory + searchback. On MIT-BIH: Sn 99.3%, PPV 99.5%.

📈 Hilbert 包絡

解析訊號 xa(t) = x(t) + j·H{x(t)}；其模 |xa| 即為訊號包絡。用於 EMG 強度、心音 S1/S2 起始點、語音語段偵測。

Analytic signal xa(t) = x(t) + j·H{x(t)}; its magnitude |xa| is the envelope. Used for EMG amplitude, heart-sound S1/S2 onsets, voice-activity detection.

⚖️ 閾值 + 不應期

簡單但極實用：求局部峰 → 設振幅閾值 → 強制連續兩偵測間距 ≥ Trefr（QRS 0.2 s、EEG spike 0.25 s）。配自適應閾值可抗振幅漂移。

Simple but very effective: find local peaks → amplitude threshold → enforce minimum inter-peak distance Trefr (QRS 0.2 s, EEG spike 0.25 s). Adaptive thresholds handle amplitude drift.

🧠 模板匹配

把已知 QRS / spike 模板與訊號做 cross-correlation，極值即為事件。對形狀變化敏感；深度學習版本即「1D CNN」。

Cross-correlate a known QRS / spike template against the signal; correlation peaks mark events. Sensitive to shape; the modern DL version is a "1D CNN."

ICA 與 EEG

七、ICA 去 EEG 假影

多通道 EEG 是多個獨立來源（皮質網絡、眼動、心電、肌電）的線性混合：x = A·s。ICA 假設來源 s 統計獨立、非高斯，估出 unmixing matrix W ≈ A⁻¹，把眼動 blink、心電污染、線性電纜雜訊等成分逐一分離後刪除，再用 W⁻¹ 重建乾淨 EEG。

主流算法：FastICA（負熵最大化）、Infomax（資訊最大化）、SOBI（二階統計）。常用工具：MNE-Python 的 mne.preprocessing.ICA、EEGLAB 的 runica。

Multi-channel EEG is a linear mixture of independent sources (cortical networks, eye movement, cardiac, EMG): x = A·s. ICA assumes statistically independent, non-Gaussian sources and estimates the unmixing matrix W ≈ A⁻¹, then removes blink / cardiac / cable-noise components and reconstructs clean EEG via W⁻¹.

Main algorithms: FastICA (negentropy max), Infomax (mutual-information max), SOBI (2nd-order). Tools: MNE-Python mne.preprocessing.ICA, EEGLAB runica.

⚠️
ICA 限制：(1) 來源必須非高斯；純白雜訊無法分離。(2) 訊號數需 ≥ 來源數，故 1–4 通道 EEG 不適合。(3) 成分順序不固定，需人或自動分類器辨識「眼動成分 vs 腦成分」。 ICA caveats: (1) sources must be non-Gaussian — pure white noise can't be separated; (2) channels must ≥ sources, so 1–4-ch EEG isn't suitable; (3) component order is arbitrary — a human or automated classifier must label "blink vs cortex."
決策樹

八、濾波器決策樹

🌳 雜訊 → 濾波器

Q1.基線漂移（< 0.5 Hz 呼吸/出汗）？→ HPF 0.5 Hz；診斷級 0.05 Hz（避免 ST 段失真）。Baseline wander (< 0.5 Hz, breathing/sweating)? → HPF 0.5 Hz; diagnostic 0.05 Hz (to avoid ST distortion).
Q2.EMG 突發污染（20–500 Hz）？→ LPF 35–40 Hz（監測級）。診斷 ECG 應改善病人放鬆而非加 LPF。EMG burst (20–500 Hz)? → LPF 35–40 Hz (monitoring). For diagnostic ECG, relax the patient rather than apply LPF.
Q3.50/60 Hz 工頻雜訊？→ Notch（Q ≈ 30–50）；首選改善 CMRR 與 DRL。50/60 Hz line interference? → Notch (Q ≈ 30–50); but first improve CMRR and DRL.
Q4.混合多種低/高/單頻雜訊？→ BPF（HPF + LPF 串接）+ notch。串級設計 (cascaded biquad) 數值穩定。Mixed low/high/single-freq noise? → BPF (HPF + LPF) + notch. Cascaded biquads stay numerically stable.
Q5.瞬態（電極 pop、肌肉抽搐）？→ 線性濾波無法解決；改用 wavelet 去噪、形態學濾波或事件偵測 + 內插。Transients (electrode pop, twitch)? → Linear filters fail; use wavelet denoising, morphological filter, or event detection + interpolation.
Q6.多通道 EEG 含眼動 / 心電污染？→ ICA（FastICA 或 Infomax），刪除 blink / ECG IC 後重建。Multi-ch EEG with blink / cardiac contamination? → ICA (FastICA or Infomax), reject blink/ECG ICs and reconstruct.
Q7.想保留 QRS 形狀的低延遲處理？→ 用 FIR 線性相位 而非 IIR；不可用 zero-phase（雙向）filtfilt 於即時。Need to preserve QRS shape with low latency? → Use FIR linear-phase filters; zero-phase filtfilt cannot run real-time.
程式示例

九、程式示例

import numpy as np
from scipy.signal import butter, filtfilt, iirnotch, find_peaks
from scipy.signal import welch

fs = 500; t = np.arange(0, 10, 1/fs)
# Toy ECG with realistic contamination
ecg = (np.sin(2*np.pi*1.2*t)
       + 0.3*np.sin(2*np.pi*0.3*t)            # wander
       + 0.4*np.sin(2*np.pi*50*t)             # power-line
       + 0.05*np.random.randn(len(t)))         # white noise

# 1) Notch 50 Hz
b0,a0 = iirnotch(50, 30, fs)
x = filtfilt(b0, a0, ecg)

# 2) Band-pass 0.5–40 Hz (Butterworth, 4th order)
b,a = butter(4, [0.5/(fs/2), 40/(fs/2)], btype='band')
x = filtfilt(b, a, x)

# 3) Pan-Tompkins: differentiate / square / integrate
b1,a1 = butter(2, [5/(fs/2), 15/(fs/2)], btype='band')
y    = filtfilt(b1, a1, x)
y    = np.diff(y, prepend=0)**2
wlen = int(0.150*fs)
mwi  = np.convolve(y, np.ones(wlen)/wlen, mode='same')
peaks,_ = find_peaks(mwi, distance=int(0.25*fs),
                     height=0.4*np.max(mwi))
hr = 60/np.mean(np.diff(peaks)/fs)

# 4) Welch PSD for HRV LF/HF
rr  = np.diff(peaks)/fs
f,P = welch(rr - rr.mean(), fs=4.0, nperseg=64)
LF  = P[(f>0.04)&(f<0.15)].sum()
HF  = P[(f>0.15)&(f<0.4)].sum()
print(f"HR={hr:.1f} bpm,  LF/HF={LF/HF:.2f}")
fs = 500; t = 0:1/fs:10-1/fs;
ecg = sin(2*pi*1.2*t) + 0.3*sin(2*pi*0.3*t) ...
    + 0.4*sin(2*pi*50*t) + 0.05*randn(1,length(t));

% Notch 50 Hz
[b0,a0] = iirnotch(50/(fs/2), 50/(fs/2)/30);
x = filtfilt(b0,a0,ecg);

% Band-pass 0.5–40 Hz
[b,a] = butter(4, [0.5 40]/(fs/2), 'bandpass');
x = filtfilt(b,a,x);

% Pan-Tompkins
[b1,a1] = butter(2, [5 15]/(fs/2), 'bandpass');
y = filtfilt(b1,a1,x);
y = [0 diff(y)].^2;
mwi = movmean(y, round(0.150*fs));
[~,locs] = findpeaks(mwi, 'MinPeakDistance', round(0.25*fs), ...
                          'MinPeakHeight', 0.4*max(mwi));
hr = 60/mean(diff(locs)/fs);
fprintf('HR = %.1f bpm\n', hr);

% HRV LF/HF via pwelch (Signal Processing Toolbox)
rr = diff(locs)/fs;
[Pxx,F] = pwelch(rr-mean(rr), [], [], [], 4);
LF = sum(Pxx(F>0.04&F<0.15));  HF = sum(Pxx(F>0.15&F<0.4));
fprintf('LF/HF = %.2f\n', LF/HF);
關鍵術語

十、關鍵術語

Nyquistfs/2，可正確還原的最高頻率。   Aliasing頻譜混疊：高頻訊號被取樣後偽裝成低頻。   FIR / IIR有限脈衝響應 / 無限脈衝響應；FIR 穩、線性相位但階高，IIR 階低但相位非線性。   Butterworth通帶最平坦的 IIR 原型；醫療最常用。   Notch窄阻帶濾波器；專門移除工頻或單一干擾。   FFTFast Fourier Transform — O(N log N) 計算 DFT。   STFT短時傅立葉變換：滑動視窗 FFT，得到 spectrogram。   CWT / DWT連續 / 離散小波變換；多解析度時間-頻率分析。   Pan-Tompkins1985 年提出的 QRS 偵測流程：BP → diff → square → MA → 雙閾值。   ICA獨立成分分析；多通道訊號的盲源分離。   HRV心率變異；SDNN、RMSSD、LF/HF。   Sample Entropy衡量時間序列規律性；越大越不可預測。
