CHAPTER B4 · BLOCK B SIGNALS & IMAGES

醫學影像處理與 AI

從 DICOM 標準、前處理、分割、分類，到 U-Net、SAM 2、放射 foundation model 與 FDA 法規（2025 年 295 件新核可）。

From DICOM, preprocessing, segmentation, classification to U-Net, SAM 2, imaging foundation models, and FDA AI/ML clearance (295 new in 2025).

DICOM 標準

一、DICOM 標準

DICOM (Digital Imaging and Communications in Medicine) 由 ACR + NEMA 自 1985 年制定，是所有 CT/MRI/X-ray/US/PET 共用的影像 + 通訊標準。一個 DICOM 檔案 = 檔案 meta-info + 一組 (Group, Element) 標籤資料 + 像素資料。

  • 檔案 meta-information：transfer syntax、preamble (DICM)、Implicit/Explicit VR Little Endian。
  • Patient / Study / Series / Instance 階層：一個病人 → 多個 Study（檢查），一個 Study → 多個 Series（同模態的序列），一個 Series → 多個 Instance（單張影像）。
  • 必要標籤：(0010,0010) Patient Name；(0008,0060) Modality；(0028,0010/0011) Rows/Columns；(0028,0030) Pixel Spacing；(7FE0,0010) Pixel Data。
  • DICOM Networking (DIMSE-C)：C-STORE（傳輸）、C-FIND（查詢）、C-MOVE（搬移）；現代 PACS 與 RIS 之間通訊。
  • DICOMweb (RESTful)：QIDO-RS（查）、WADO-RS（取）、STOW-RS（存）；雲端醫療影像必備。
  • DICOM SR (Structured Report)：結構化報告；AI 推論結果回寫 PACS 的標準載體（如 mammography CAD 結果）。

DICOM (Digital Imaging and Communications in Medicine), jointly developed by ACR + NEMA since 1985, is the universal imaging + communication standard for CT/MRI/X-ray/US/PET. One DICOM file = file meta + (Group, Element) tag dataset + pixel data.

  • File meta-info: transfer syntax, preamble (DICM), Implicit/Explicit VR Little Endian.
  • Patient / Study / Series / Instance hierarchy: 1 patient → many studies (exams), 1 study → many series (same modality sequences), 1 series → many instances (slices).
  • Key tags: (0010,0010) Patient Name; (0008,0060) Modality; (0028,0010/0011) Rows/Columns; (0028,0030) Pixel Spacing; (7FE0,0010) Pixel Data.
  • DICOM Networking (DIMSE-C): C-STORE / C-FIND / C-MOVE — used between PACS and RIS.
  • DICOMweb (RESTful): QIDO-RS / WADO-RS / STOW-RS — cloud medical imaging.
  • DICOM SR (Structured Report): the standard carrier for AI inference results written back to PACS (e.g., mammography CAD output).
⚠️
常見陷阱：(1) Pixel Spacing 不是 mm/像素恆定，需讀標籤而非假設。(2) Rescale Slope/Intercept 必須套用後才能正確顯示 HU。(3) Photometric Interpretation = MONOCHROME1 時黑白要反轉。(4) 去識別化必須移除 (0010,xxxx) 與 burnt-in pixel text，符合 HIPAA Safe Harbor 18 識別字段。 Common pitfalls: (1) Pixel Spacing varies — read the tag, don't assume mm/pixel. (2) Rescale Slope/Intercept must be applied for correct HU display. (3) MONOCHROME1 needs B/W inversion. (4) De-identification must remove (0010,xxxx) tags and burnt-in pixel text per HIPAA Safe Harbor's 18 identifiers.
前處理

二、前處理

🪟

① Windowing

CT 像素為 12–16 bit (HU) 但顯示器只有 8 bit；用「窗位 WL + 窗寬 WW」線性映射子範圍：肺窗 (WL −600, WW 1500)、骨窗 (300, 1500)、腦窗 (40, 80)、軟組織 (50, 350)。

CT pixels are 12–16-bit HU but displays are 8-bit; "window level + width" linearly maps a sub-range — lung (WL −600, WW 1500), bone (300, 1500), brain (40, 80), soft tissue (50, 350).

🌀

② Bias-field 校正

MRI 受 RF 線圈不均勻導致亮度低頻偏移；N4ITK 用 B-spline 估計乘性偏壓場後除去，是 nnU-Net 預處理預設步驟。

MRI suffers a smooth multiplicative intensity bias from RF coil non-uniformity; N4ITK fits a B-spline bias field and divides it out — a default step in nnU-Net preprocessing.

📊

③ Intensity 正規化

不同機台/協定的 MRI 像素並無物理單位；常做 z-score（(x−μ)/σ）、histogram-matching（Nyúl）、percentile clipping (1–99%)。

MRI pixels lack physical units; normalize by z-score ((x−μ)/σ), histogram matching (Nyúl), or percentile clipping (1–99%).

📌

④ Registration 對位

剛體 (rigid) → 仿射 (affine) → 變形 (deformable, B-spline / Diffeomorphic SyN)。工具：ANTs SyN、elastix、SimpleITK；DL 對位：VoxelMorph、TransMorph。

Rigid → affine → deformable (B-spline / Diffeomorphic SyN). Tools: ANTs SyN, elastix, SimpleITK; DL alternatives: VoxelMorph, TransMorph.

分類 + 基礎模型

四、分類與基礎模型

影像分類演進：AlexNet (2012) → VGG/Inception/ResNet (2014–15) → EfficientNet (2019) → ViT (2020) → Foundation Models (2023–2025)。醫療影像分類的轉折點：(1) ImageNet 預訓練 → 微調（典範至 2022）；(2) 大規模醫療影像自監督預訓練（DINOv2、SimCLR）；(3) 領域基礎模型（病理 / 放射 / 眼底各有專屬 FM）。

Imaging classification evolution: AlexNet (2012) → VGG/Inception/ResNet (2014–15) → EfficientNet (2019) → ViT (2020) → Foundation Models (2023–2025). Two inflection points: (1) ImageNet pre-train + fine-tune (the dominant pattern through 2022); (2) large-scale medical self-supervised pretrain (DINOv2, SimCLR); (3) domain foundation models (pathology / radiology / fundus each have their own).

FDA 法規

五、FDA AI/ML 法規

關鍵數字（截至 2025/12）：

  • FDA 累計核可 1,451 件 AI/ML 啟用醫療裝置。
  • 2025 年單年新增 295 件，創歷史紀錄。
  • 76% 為放射影像（CT/MR/X-ray/mammography/PET）；其次心血管 (9%)、神經 (3%)。
  • 絕大多數透過 510(k)（實質等同）；少數 De Novo 與 PMA。
  • 2025/2 通過首件「影像 Foundation Model」：Tempus CARE1。

SaMD 框架（Software as a Medical Device）依「healthcare situation × healthcare decision」分四級 I–IV；AI 影像辨識多落在 II–III。

PCCP（Predetermined Change Control Plan）：FDA 2024/12 終版指引，允許 AI/ML 廠商在事前聲明的範圍內，無需每次重送 510(k) 即可更新模型（如重新訓練、加入新族群、改 hyperparameter）；2025 已有 50+ 件採用 PCCP。

GMLP（Good Machine Learning Practice）：FDA + Health Canada + UK MHRA 聯合 10 條原則（2021）；2024 補充 GMLP 透明度 7 條原則、2025 進一步收緊資料倫理與後市監測。

Key numbers (as of Dec 2025):

  • Cumulative FDA-authorized AI/ML medical devices: 1,451.
  • 2025 added 295 in one year — record.
  • 76% are radiology (CT/MR/X-ray/mammography/PET); cardiovascular (9%), neurology (3%) follow.
  • Most cleared via 510(k); few De Novo or PMA.
  • Feb 2025: first "imaging foundation model" cleared — Tempus CARE1.

The SaMD framework categorizes software by "healthcare situation × healthcare decision" into Class I–IV; AI imaging typically lands in II–III.

PCCP (Predetermined Change Control Plan): final FDA guidance Dec 2024 — vendors can pre-declare allowable model updates (retraining, new populations, hyperparameter changes) without re-submitting a 510(k). 50+ submissions in 2025 used PCCP.

GMLP (Good Machine Learning Practice): 10 joint principles from FDA + Health Canada + UK MHRA (2021); 2024 added 7 transparency principles; 2025 tightened data ethics and post-market surveillance.

決策樹

七、分割演算法決策樹

🌳 分割演算法 → 選擇

Q1.是否有標註資料 ≥ 200 例？→ 否：先試 SAM 2 / MedSAM-2 zero-shot（點/框 prompt）；標註幾十例後微調。Labeled data ≥ 200? → No: try SAM 2 / MedSAM-2 zero-shot (point/box prompts); fine-tune after labeling dozens.
Q2.有 200–2000 例、單一明確任務（單器官 / 病灶）？→ nnU-Net（自動配置，幾乎不用調參）。200–2000 cases, single well-defined task (one organ/lesion)? → nnU-Net (auto-configures, near-zero tuning).
Q3.資料量 > 5000 例 + 多任務 + 算力充足？→ TransUNet / Swin-UNet 或 ViT 骨幹，獲取長距離 context。> 5000 cases + multi-task + ample compute? → TransUNet / Swin-UNet or ViT-based, for long-range context.
Q4.需要互動式分割（放射師在 PACS 上點幾下）？→ SAM 2 + GUI 整合（如 3D Slicer SAM extension、MONAI Label）。Interactive segmentation (radiologist clicks in PACS)? → SAM 2 + GUI integration (3D Slicer SAM extension, MONAI Label).
Q5.超快/低算力、邊緣裝置？→ 輕量 U-Net（MobileNet 骨幹）或經典 Otsu + 形態學。Ultra-fast / edge device? → Lightweight U-Net (MobileNet backbone) or classical Otsu + morphology.
Q6.CT/MR 三維體積？→ 用 3D nnU-Net，並啟用 patch-based 訓練、cascade（粗 → 細）。3D CT/MR volume? → 3D nnU-Net with patch-based training and cascade (coarse → fine).
Q7.要符合 FDA 510(k)？→ 選擇可解釋、可驗證的模型；準備 GMLP 文件 + PCCP；驗證資料須包含 site/scanner 變異。Aiming for FDA 510(k)? → Pick explainable, validatable models; prepare GMLP docs + PCCP; validation must span sites/scanners.
程式示例

八、DICOM 讀取與 Otsu

import pydicom, numpy as np
import matplotlib.pyplot as plt
from skimage.filters import threshold_otsu
from skimage import morphology, measure

# 1) Load DICOM and apply HU rescale
ds  = pydicom.dcmread("chest_ct.dcm")
img = ds.pixel_array.astype(np.float32)
slope     = float(ds.get("RescaleSlope", 1))
intercept = float(ds.get("RescaleIntercept", 0))
hu  = img * slope + intercept                # now in Hounsfield Units

print("Patient ID:", ds.PatientID,
      "Modality:", ds.Modality,
      "Shape:", hu.shape,
      "Pixel spacing (mm):", ds.PixelSpacing)

# 2) Window for soft tissue (WL 50, WW 350)
wl, ww = 50, 350
win    = np.clip((hu - (wl - ww/2)) / ww, 0, 1)

# 3) Otsu auto-segment, clean with morphology, label
thr  = threshold_otsu(win)
mask = win > thr
mask = morphology.remove_small_objects(mask, min_size=256)
mask = morphology.binary_closing(mask, morphology.disk(3))
lbl  = measure.label(mask)
print("Detected objects:", lbl.max())

fig, ax = plt.subplots(1, 3, figsize=(10,3.5))
ax[0].imshow(win, cmap='gray');  ax[0].set_title('Windowed')
ax[1].imshow(mask, cmap='gray'); ax[1].set_title(f'Otsu (thr={thr:.2f})')
ax[2].imshow(lbl,  cmap='tab20'); ax[2].set_title('Labeled')
plt.tight_layout(); plt.show()
% Requires Image Processing Toolbox
info = dicominfo('chest_ct.dcm');
img  = double(dicomread(info));

% Rescale to Hounsfield Units
slope = info.RescaleSlope;  intercept = info.RescaleIntercept;
hu    = img*slope + intercept;
fprintf('PatientID: %s  Modality: %s  Spacing: %.2f mm\n', ...
        info.PatientID, info.Modality, info.PixelSpacing(1));

% Soft-tissue window (WL 50, WW 350)
WL = 50; WW = 350;
win = (hu - (WL - WW/2)) / WW;
win(win<0) = 0; win(win>1) = 1;

% Otsu + morphology + connected components
thr  = graythresh(win);            % Otsu in MATLAB
mask = imbinarize(win, thr);
mask = bwareaopen(mask, 256);     % remove tiny objects
mask = imclose(mask, strel('disk',3));
lbl  = bwlabel(mask);
fprintf('Detected objects: %d\n', max(lbl(:)));

subplot(1,3,1); imshow(win,[]);    title('Windowed');
subplot(1,3,2); imshow(mask);      title(sprintf('Otsu thr=%.2f',thr));
subplot(1,3,3); imagesc(lbl);      title('Labeled'); axis image;

九、關鍵術語

DICOMDigital Imaging and Communications in Medicine — 醫療影像通用標準。   PACSPicture Archiving and Communication System — 醫院影像儲存/查閱系統。   WL / WWWindow Level / Width — CT 顯示時的中心與寬度。   N4ITK改良 N3 的 MRI bias-field 校正；nnU-Net 預設步驟。   U-Net2015 Ronneberger 提出；encoder-decoder + skip；醫療影像分割黃金基準。   nnU-Net2021 Isensee 提出；自動配置的 U-Net 框架。   SAM 2Segment Anything Model 2（Meta 2024）；prompt-based、可處理影像+影片。   Otsu1979 提出；自動選最大化類間變異的閾值。   Dice2|A∩B|/(|A|+|B|)；分割評估標準指標，0–1。   Foundation model大規模自監督預訓練、可下游 zero-shot / few-shot 的通用模型。   SaMDSoftware as a Medical Device — 軟體本身即醫療器材；FDA 與 IMDRF 框架。   PCCPPredetermined Change Control Plan — 預先載明 AI 模型更新範圍，免重送 510(k)；FDA 2024/12 終版指引。   GMLPGood Machine Learning Practice — FDA + Health Canada + UK MHRA 聯合 10 條原則 (2021)。   DICOM SRStructured Report；AI 推論結果寫回 PACS 的標準。
